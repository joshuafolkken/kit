# Issue-Driven Collaboration Workflow

An index of the Issue-driven workflow's rule files, one per topic, shared by every AI tool (Claude /
Cursor / Gemini). It is for a person browsing; it is not where a rule is defined, and no session reads
it. Open the one file you need.

A document that points at a topic cites the file that holds the body, never this index
([`residency.md`](../prompts/collaboration-workflow/residency.md)).
