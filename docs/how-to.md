# How-to guides

For anyone who knows what they want to do but not which command does it. Each guide covers one task: when to use it, the steps in order, how to check it worked, and the usual failures. The guides link to the reference for arguments and details rather than repeating them — [josh-commands.md](./josh-commands.md) stays the single source for every command.
